# BBCA_Stock_Prediction
Comparative Analysis of Linear Regression, LightGBM, and XGBoost in Predicting BBCA Stock Trends for Investment Decision Making

This study conducts a comparative analysis of three machine learning algorithms—Linear Regression, Light Gradient Boosting Machine (LightGBM), and eXtreme Gradient Boosting (XGBoost)—for predicting BBCA stock trends to support investment decision making. Using historical daily OHLCV data from BBCA enriched with technical indicators such as Simple Moving Averages, Exponential Moving Average, Relative Strength Index, and MACD, each model is trained and evaluated on a time-series-aware split to avoid data leakage. Model performance is quantitatively assessed using Root Mean Squared Error (RMSE), Mean Absolute Percentage Error (MAPE), and the coefficient of determination (R²) to identify the most accurate and reliable predictor. The results show that Linear Regression achieves the lowest RMSE and MAPE and the highest R², outperforming both LightGBM and XGBoost despite their higher model complexity. These findings indicate that the underlying pattern of BBCA stock price movements in the engineered feature space is predominantly linear, making Linear Regression the most suitable model for this case. The study highlights the importance of model simplicity, interpretability, and rigorous evaluation in constructing practical decision-support tools for stock investment.
